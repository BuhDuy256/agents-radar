### ReptClip turns any free chatbot site into a VS Code coding agent
The author built ReptClip, a free open-source VS Code extension that copies project context to the clipboard, lets you paste it into any free chatbot, then applies the chatbot's code blocks as Search/Replace diffs back into your files. Context selection supports paths and glob patterns; v2.0 adds `cat`, `grep` and `read-lines` commands the chatbot can request mid-conversation. Diffs apply all-or-nothing, only files tracked by git are touched, and there are 10 levels of diff-specific undo. The author reports roughly 1,500 lines of external contributions hardening symlink, `.git` and `.gitignore` handling. Install from the VS Code Marketplace or Open VSX.

### A 60-line Python script measures any remote MCP server's tool tokens
A remote MCP server ships every tool's name, description and input schema into the model's context at conversation start, and this script estimates that cost. It runs `initialize`, then `notifications/initialized`, then `tools/list` over HTTPS POST, follows `nextCursor`, and handles both plain JSON and `text/event-stream` replies. Tokens are approximated at roughly four characters of compact JSON each, and the script flags tools with short descriptions and parameters with none. Real output ranged from DeepWiki's three tools at about 426 tokens to Context7's two tools at about 1,306. The author notes the default `Python-urllib` user agent gets 403s, so any honest `User-Agent` fixes it.

### A RAG system that verifies every sentence loses throughput under overload
The author rebuilt a three-paper RAG system so each sentence is checked against its cited passage before display; verification runs as the answer streams, and a failed sentence stops the answer. Under normal bursts the first verified sentence arrived at a median 324.5 ms, versus 614.2 ms before. Under heavy overload the new version delivered 62.8% of requests against 67.4% previously, which the author attributes to the checker halting responses. The system used Groq's free tier with BM25 plus embeddings and no vector database, and the author reports the slowest request spent 29.2 of 29.8 seconds waiting on quota rather than working.

### A 220,226-tool MCP scan found almost no injection but broad credential access
Serverdex scanned tool definitions from 12,987 MCP servers, 220,226 tools total, on 21 Nov 2026 for injected instructions, hidden characters and sensitive-file access. The scan found zero descriptions telling a model to ignore instructions and zero zero-width characters; sensitive-file hits were all benign on inspection, including security scanners describing what they detect. The scan did find 3,053 servers, 23.5%, with a tool handling credentials, tokens or API keys, plus 188 with shell or code execution and 163 that read local files. The author states the scan reads descriptions, not intent or runtime behaviour, so it measures surface area rather than safety.
