## Experiments and comparisons
### Same weights, different engine numerics flip gsm8k answers
The author ran DeepSeek-R1-Distill-Qwen-7B Q8_0 greedy on 600 gsm8k problems, switching between two engines running the same weights with different numerics. Most answer texts changed and correctness flipped on 53 problems — 25 became wrong, 28 became right, a net change of 3. A separate run on llama.cpp's server with eight concurrent requests differed from one-at-a-time on 41 of 100 gsm8k problems, moving strict-match from 0.83 to 0.82. The author attributes this to floating-point reduction order changing with batching, prompt cache and speculative decoding, not to temperature or seed. The limit: results depend on model, GPU and build, so compare outputs item by item rather than scores.

### Memory strategy, not accuracy, drove the token bill over 30 turns
The author benchmarked three memory strategies on the same 30-turn reasoning-chain task with GPT-4o, using June 2024 pricing ($5/M input, $15/M output). Full context scored 0.94 accuracy at $0.1122; selective recall (window 4) scored 0.91 at $0.0486; retrieval-augmented external memory (top_k 4) scored 0.84 at $0.0434. Full recall roughly tripled cost for a small accuracy edge and, the author says, becomes unsustainable past 20–30 turns, while external memory is the only approach that holds cost stable as sessions grow. The suite is reproducible via the author's repo; the comparison is one task on one model, so it does not prove one strategy is best generally.
