### Simulated first-time-user personas audit an app's onboarding for blockers
The author built First User Audit, an open-source Agent Skill that guides a coding agent to explore an app from four simulated first-time-user behaviors: Impatient, Skeptic, Mobile (375px viewport), and Breaker. The workflow identifies what "first success" means, runs the four personas in fresh browser sessions, records blockers with browser evidence and reproduction steps, prioritizes issues, and proposes bounded fixes. Installable via the skills CLI or a copy-paste prompt.

### An MCP security checklist before wiring agents to real tools
Carlos (Bloqarl) published a 24-point checklist for connecting agents to tools through MCP, where the server usually runs with the user's keys and network access. The checks cover path traversal, command injection, execute primitives in git, write boundaries, injected instructions in tool output, hidden content, exfiltration, tool descriptions, hardcoded credentials, scoped keys, process least privilege, dangerous server combinations, shared context, supply chain, context pollution, SSRF, rate limits, and logs with arguments. The author recommends picking three if nothing else: no shell strings built from model input, no long-lived broad keys, and treating every tool result as attacker-written. ### Temperature 0 still varies: batching and cache change the computed logits
The author found llama.cpp's server (build b11643, Qwen2.5-7B-Instruct Q8_0, `-np 8`) produced different greedy output on 41 of 100 gsm8k problems when one request ran alone versus eight concurrent requests; the strict-match score moved from 0.83 to 0.82. The author explains that temperature and seed pick the next token but do not fix the probabilities, and floating-point addition order changes with batch size, prompt cache chunking, speculative decoding, and GPU or kernel versions. The post includes a script to reproduce the alone-versus-concurrent comparison on any OpenAI-compatible server. Limit: how often it differs depends on the model, GPU and build.
