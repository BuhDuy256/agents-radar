### A 24-item MCP checklist covers what to audit before shipping an agent
Carlos (Bloqarl) wrote a pre-ship checklist for connecting agents to real tools over MCP, the protocol that lets a model call servers for files, git, databases or email. The 24 items span server code (path traversal, command injection, writes to config or hooks), prompt injection in tool output, credentials and scoping, combinations of servers in one agent, supply chain, context separation, and network limits like SSRF and spend caps. Cited 2025 research says 82% of studied servers used file operations prone to path traversal and 53% relied on static credentials. The author's short version: no shell strings built from model input, no long-lived broad keys, and treat every tool result as attacker-written.

### Ten reruns failed to rediscover a DNA array Claude found once
According to Anthropic, an AI research campaign of 949 agent sessions over 21.5 hours found the ART system, a repeat array beside a reverse transcriptase gene in bacteriophage DNA. Rerunning the same harness and brief ten times, none of the campaigns identified the repeat array in the rerun analysis, though nearly all sampled the ART loci. In separate evaluations, the strongest models described the array in at least 90% of attempts when the sequence was placed in context, but Opus 5 dropped to 32% in one file-based condition. Limit: the array was not characterized before; the result shows a reproducibility problem in agent investigation, not that the discovery was wrong.
