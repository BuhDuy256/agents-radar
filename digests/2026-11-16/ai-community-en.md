### Gating agent edits with Claude Code hooks instead of prompt rules
The author moved rules out of `CLAUDE.md` and into Claude Code hooks, which the harness runs at lifecycle events like `PreToolUse`, `PostToolUse` and `Stop`. A `PreToolUse` bash hook blocks reads and edits of secret files by exiting with code 2; a `PostToolUse` hook formats only the file just edited; a `Stop` hook blocks Claude from finishing while type-checks fail. The author notes only exit code 2 blocks a tool call — exit 1 is a non-blocking error — and that `PreToolUse` cannot stop a `Bash` call such as `cat .env`.
