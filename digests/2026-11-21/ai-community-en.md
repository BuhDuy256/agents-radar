### Strands benchmark: mixed orchestrators cost up to 192.8% more model tokens
The author ran nine experiments on the open-source Strands Agents SDK inside one process, putting a Graph, a vended Workflow tool, and a Swarm on the same task, with Bedrock as the model. ### SWE-sweep makes coding agents discover bugs without a bug report
Meta researchers, including two SWE-bench creators, published SWE-sweep on 1 October 2026: a benchmark where an agent gets a real repository and no hint about what is broken. It spans 4,068 known bugs across 100 repositories and 22 languages, with fixes verified by hidden tests. The best model tested fixed only 4.7 percent, so discovery rather than repair is the bottleneck. The GitHub repo has 246 stars, no release, and no stated licence. Teams building coding agents can run their own agent against it to measure discovery separately from repair.
