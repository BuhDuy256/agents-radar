### Guard agent skills against drift with a scheduled six-step feedback loop
The author audited publishing-kit, an agent skill that publishes one markdown article to five destinations, and found six kinds of drift while its checks stayed green. The pre-flight exited 0 on the audit day, yet a code review found 20 issues and manual generator runs added 2 more. The loop: observe a real run, measure and archive dated output, encode a guard in the script, verify the test fails on old code, release with a version bump and install update, then repeat. Closing install drift first matters most, because sessions loading a stale snapshot cannot see any later fix.

### Turn CI reports into a published dashboard with 3σ bands
The author built one static HTML dashboard from a GitHub Actions run's own artifacts, with inline SVG charts, no scripts, no CDN and no database. Eleven YAML bands compare each `main` run against the previous 20 days; 1σ logs, 2σ annotates, 3σ fails the job so Pages doesn't publish. A `minSigma` floor stops flat baselines from flagging noise, a band stays inert until it has five days of history, and missing input never fails the build. Published figures include 92.7% line coverage and 701 unit tests in 5.5s.

## Experiments and comparisons
### Provider-side test shows HTTP abort may not stop LLM inference
The author ran a mock provider in `HONOR_ABORT` and `IGNORE_ABORT` modes with identical client code, then tested DeepSeek's streaming endpoint against its `GET /user/balance` meter. In the mock, honoring abort produced roughly 21 generated and 21 billed; ignoring abort produced roughly 100 and 100. In the DeepSeek run, later abort points cost proportionally more than earlier ones after a control request of all 8,000 tokens dropped the balance about 0.03–0.04 CNY. The author's claim is that `AbortSignal` proves only what the HTTP client did, not that inference or billing stopped.
