### JoeBro shares one MCP memory across Claude Code, Codex and OpenCode
The author of JoeBro, a free GPLv3 Mac app, built a local MCP server over one SQLite file so three agents read and write the same memory. It exposes `memory_remember`, `memory_recall`, `memory_supersede` and `memory_forget`; facts carry kind, project scope and provenance (agent, model, machine), and writes refuse obvious secrets. Housekeeping uses arithmetic instead of a model: 0.8 Jaccard similarity reinforces instead of duplicating, decay has a 30-day half-life, and a nightly pass archives facts below 0.12 strength, capped at 150 active facts per project. At session start each agent gets a brief of at most 400 tokens. Install requires macOS 26+.

### otomode lets Claude Code run unattended for 8 hours, committing per task
The author wrote an otomode skill in the multi-model-orchestra repo so Claude Code could work on a task list while away. Starting it with a duration asks once for tasks, a check command per task, permissions and limits, then it writes `OTOMODE.md`, creates a branch, enables a hook, and schedules an hourly watchdog. That hook denies every prompt and question (logging them to `QUESTIONS.md`) and refuses hard-to-undo commands like `rm`, `git push`, `reset --hard` and `gh pr create`. One 8-hour Go + React run finished 16 tasks with about 25 commits, denied 15 prompts, paused at 87% usage and pushed nothing; it is one run, not a benchmark.

### Permission rules matched wall commands only after wildcards on both sides
The author ran two DigitalOcean Managed Agents sessions (claude-code harness, Sonnet 5.5, 2 vCPU) against a small public Python repo. With `default: allow` and literal `git push *` / `gh pr create *` rules, the first run pushed and opened PR #10 without one approval: the actual command began with `cd` and chained both actions. Switching patterns to `*git*push*` and `*gh pr *` made each gated command wait — one push waited 3 min 24 s, a retry needed its own approval, and a rejected `gh pr comment` was not retried. The author notes string matching misses script files, aliases and subprocess calls. Two runs on one repo prove nothing general.
