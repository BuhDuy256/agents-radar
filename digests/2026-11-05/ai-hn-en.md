### Anthropic releases FlashProve, an open-source prototype for proving which model produced a response

Anthropic announced FlashProve, a system that lets a model provider prove each response came from a committed model without revealing its weights. For a 400B-parameter Llama 4 Maverick at 4-bit quantization, the company says a single H100 GPU generates proofs at around 110 tokens/second with ~19 MB of proof per 1,024-token request, about 70-95x the GPU time of running the model on vLLM. Anthropic released code, a Lean-verified verifier, and a protocol spec under Apache 2.0, and states the work is intermediate progress, not a finished agenda.

### TypeSafe argues against calling its Jev model a "decision model"

TypeSafe published a post arguing its Jev model should be called a System One model, not a decision model, because Jev makes judgments while code makes decisions. The author recommends decomposing a workflow into atomic judgments and logic paths: Jev answers only the small questions code cannot, and logic combines those answers into a decision. The stated purpose is clarity of design and observability; a single Choice question with stacked criteria prose tends to produce repeated "prompt gymnastics" as new edge cases appear.
