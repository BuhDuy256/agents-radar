### A verifier turns one repo's AI-written README into a review queue of 47 claims
The author built Doxify, a local CLI that compiles a git repository into evidence cards, has Gemma write only from those cards, then lets a deterministic verifier decide which sentences survive. The result the author reports on `nextjs-dashboard`: 13 of 47 claims verified, 34 flagged `[needs evidence]`, none rejected. The 34 flags are the review queue, not a failure. Doxify runs on an 8 GB CPU-only laptop with `gemma3:1b` through Ollama, no API key and no upload; the installer sets up an isolated `uv` environment and runs `doxify self-check`. Use it when you have shipped a repo but not explained it.

### Swapping the Responses API for Chat Completions lifted one agent's citation rate
The author ran a pre-registered series of single-change experiments on one agent framework, comparing citation survival rate (CSR) on the same 127 questions with question-by-question paired bootstrap intervals. Original config scored 0.333 on re-run versus 0.323 published, so the effect replicated. Setting temperature to 0 gave +0.082, not significant; the recommended MCP tool description gave no effect.
