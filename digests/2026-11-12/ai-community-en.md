### Eval gate blocks a pull request when an agent's answers drop below 4/5
The author added an eval gate to a scaffolded agent so a failing score blocks merges. Agents CLI v1.13.0 ends `eval run` with `RESULT: PASS` or `RESULT: FAIL`, and a missed threshold or any errored case exits 1, which CI already reads as failure. The author ran `agents-cli eval run --fail-under custom_response_quality=4`, then broke the agent's instruction on purpose; the placeholder unit test still passed while the eval failed. The GitHub Actions step runs `uvx google-agents-cli eval run`, and marking the `test` job required needs the workflow's `paths:` block deleted. Three eval cases is a small gate.

### Kiro CLI reviews pull requests in a GitHub Action and posts one comment
A Developer Advocate at AWS set up a CI job where Kiro CLI reviews each pull request diff and posts the review as a PR comment. The agent is a Markdown file in `.kiro/agents/` with `tools: ["read"]` and deny rules for file writes, shell and web fetch. The workflow installs Kiro CLI, diffs against the base branch, caps the diff at 150 KB, pipes it into `kiro-cli chat --v3 --no-interactive`, and posts with `gh pr comment --edit-last --create-if-none`. Fork PRs are skipped because they don't get secrets. The author suggests leaving it comment-only before letting it block merges.

### OpenAI says Control Room stops research model output within 35 seconds
OpenAI says it deployed Control Room across its research infrastructure, a central system that can halt model output within 35 seconds after a decision to pause or terminate a job. A workload requests a job ID, attaches it to every inference request, and the inference engine checks the ID with the central service before generating output. The check sits outside the experiment's own code, so a shutdown doesn't depend on the workload carrying out the instruction. If Control Room becomes unavailable, inference requests are denied. The company says the 35-second delay comes from cached permissions and it wants to reduce it.
