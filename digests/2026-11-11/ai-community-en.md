### Update all coding agents on a Linux machine with one command
The author built a set of Bash scripts, `update-agents`, that bring Claude Code, the OpenAI Codex CLI and Antigravity's CLI, hub and IDE to their latest releases in one run. `--check` reports installed versions and changes nothing; each per-agent script can run alone; a failing installer is recorded and the rest continue, with exit 1 naming the failure. The hub and IDE tarball installs cannot self-update, so `agy-update` reads the release channel, compares versions with `sort -V`, downloads, verifies a sha256 where published, and swaps in a staged copy, keeping the previous one as `.prev`.

### RAG moved a local 8B model from 1/10 to 9/10 on KEDA questions
The author tested OzAI, a self-hosted Qwen3 8B stack on a 16 GB MacBook Pro, with 10 strict KEDA questions scored by required terms. Without RAG it answered 1 correctly, inventing a Kafka `lagThreshold` of 1000 against the documented 10. A hand-written 160-line RAG script over 165 chunks of KEDA docs reached 6/10; smaller chunks changed nothing, adding a keyword score to cosine (hybrid search) reached 8/10. The last two failures looked like reasoning, but the model stayed wrong with thinking mode enabled, at 27 and 41 seconds. Five questions per configuration can't prove hybrid search beats any other method in general.
