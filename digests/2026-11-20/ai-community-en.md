## Experiments and comparisons

### Excluding inline code before pasting made LinkedIn add 41 bogus link marks
The author measured how LinkedIn's article editor rewrites a saved article, comparing the walk-through's 269-tag source to what the editor stored after a reload. Inline code was shown in the editor but 0 of 40 code marks survived reload, while the editor auto-linked bare host-like text such as `make-medium.py` into `http://make-medium.py`. Removing inline code spans first added 41 link marks for 4 real targets; leaving the spans in place added none and preserved 4 of 4 targets. Only links whose text is inline code were unwrapped, since the editor's code mark excludes other marks.
